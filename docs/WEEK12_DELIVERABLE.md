## Official Week 12 flow
1. Run a blameless team retrospective.
2. Prepare a short presentation following problem → solution → architecture → live demo → lessons learned.
3. Rehearse the exact demo path and include one graceful failure.
4. Present and demo the deployed application.
5. Defend each member's own code individually and without AI.

## AI policy
AI is OFF for the actual oral defense. The defense guide is preparation material only and is not a substitute for understanding one's own code.

## Evidence
These files document preparation. Actual deployment status, rehearsal completion, board ownership, commit history, and individual defense completion require real team evidence.
