# Deliverable 4 Final Checklist

## Team — 50 points

- [ ] Live public URL works.
- [ ] CRUD works end to end in production.
- [ ] Edge cases and failure paths are graceful.
- [ ] Test matrix is complete.
- [ ] Automated test suite passes.
- [ ] P0/P1 bugs are resolved.
- [ ] Professional deck is ready.
- [ ] Live demo is rehearsed.
- [ ] Backup demo evidence exists.
- [ ] Retrospective is complete.

## Individual — 50 points

- [ ] Own bug-fix commits are visible.
- [ ] Meaningful test contribution is visible.
- [ ] Week 9 AI-code review participation is visible.
- [ ] Board ownership aligns with commits.
- [ ] Unassisted oral defense is completed.

## Release safety

- [ ] No secrets are committed.
- [ ] Production credentials are environment-based.
- [ ] Debug is disabled in production.
- [ ] Public URL is recorded.
- [ ] Live smoke test includes a success path and a failure path.

## Evidence rule

Do not substitute preparation documents for actual runtime, board, review, deployment, or defense evidence.
