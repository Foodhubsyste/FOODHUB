# Week 9 Deliverable — Reviewing Code (Especially the AI's)

## Goal

Use peer review to decide whether AI-assisted code is safe, correct, readable, consistent, and meaningfully tested before it merges.

## Included

- [x] Peer-review checklist
- [x] Find-the-flaw exercises
- [x] Week 9 AI prompt log
- [x] Review-regression test
- [x] AI-assisted contribution branch and pull request

## Review areas

- Correctness
- Readability
- Consistency
- Security
- Tests

The lab requires at least one substantive review comment and asks reviewers to label feedback as blocking or nit.

## Merge gate

The lab requires passing tests plus one approving review before merge. Review comments should be addressed and review should be re-requested before the merge.

This repository does not claim a peer approval or branch-protection setting that has not actually been observed.

## Evidence to complete with the team

Record the teammate-reviewed PR, substantive comment, fixes made, approval, and test result.

## AI disclosure

Week 9 is AI ON, but AI output is the subject of review. The prompt log records the prompts used to scaffold the contribution and the review artifacts.
