# FOODHUB Final Demo Click-Path — Week 12

## Pre-demo
- Verify the deployed public URL is reachable.
- Open a clean browser session.
- Prepare backup screenshots or a short recording.
- Use safe demo records that can be removed afterward.
- Confirm each member's presentation section.

## Demo path
1. Open the public application and show the role-selection screen.
2. Select Admin and sign in.
3. Show Dashboard metrics and recent activity.
4. Open Menu and create a temporary item.
5. Edit the item and show the updated value.
6. Delete the temporary item and show the confirmation prompt.
7. Select Customer and enter customer details.
8. Browse the menu and add an item to the cart.
9. Choose Pickup or Delivery and schedule the order.
10. Place the order.
11. Return to Admin and show the order.
12. Update its status/payment information.
13. Demonstrate one safe validation failure and show the visible error.
14. Trace the action through the application architecture.

## Backup plan
If the live deployment fails, use prepared screenshots or a short recording. Do not describe a failed live deployment as successful.
